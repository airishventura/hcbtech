# Editable model sources

Current exterior pilots are authored procedurally in `scripts/build-pilot-models.mjs` and exported to `public/models/`. Their registry is `models/pilots.json`. No measured Blender/CAD sources have been supplied or created.

For future measured work, save `<model-id>/source.blend`, reference photos, dimensions, orientation and revision notes here. Photo-based pilots have no verified scale or exact price-variant mapping; do not convert their visual units into engineering dimensions.
