# Catalog images

`visual-*.webp` are the existing generated illustrations, labeled as visualizations.
`products/photo-*.webp` are optimized full-frame owner photos used in five reference galleries. Original JPEGs, source filenames, hashes and inferred family classifications live under `assets/` outside the deployment directory.

Images do not establish exact model IDs, dimensions or performance. See `assets/README.md` and `docs/DEVELOPMENT-PLAN.md` in the repository.
