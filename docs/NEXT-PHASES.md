## Phase 2 — Individual 3D models

Use exact variant photographs to improve exterior approximations and create separate layouts where the physical units differ. Do not make fourteen nearly identical models solely to match fourteen price rows. Record shared chassis and drive differences explicitly. Collect width/depth/height and additional views as they become available, then replace visual scale with measured geometry. Keep every unmeasured model labeled as an approximation.

Deliverable: approved exterior models per distinct machine, editable source, posters and provenance; optional variant-specific drive changes when established. Test loading, orbit, touch, fullscreen, PNG export and low-end physical Android performance. Do not add operating animations or hidden mechanisms from guesswork.
